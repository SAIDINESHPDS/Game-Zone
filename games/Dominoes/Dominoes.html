Official Dominoes Rules

1. Tile Set: Standard 28 Double-Six set (0-0 to 6-6). 2 players receive 7 tiles; 4 players receive 5 tiles.

2. First Turn: The player holding the highest double tile (e.g. 6-6, 5-5) leads the game. If nobody holds a double, the heaviest pip tile opens.

3. Snaking Chain & Order: Connected touching sides must match identically (e.g., 4-1 with 1-4, 4-5 with 5-6). The chain snakes cleanly across the board.

4. Stock & Passing: If you have no valid move, draw from the Boneyard. If empty, click Pass Turn.

5. Blocked Match: If all players pass consecutively and no one can play, the player with the lowest remaining pip count wins the round!

6. Scoring: The round winner receives the total pip count of all opponents' remaining tiles.
